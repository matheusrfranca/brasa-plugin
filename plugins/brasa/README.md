# Brasa

Liga o Claude Code ao Brasa, o estúdio de anúncios com IA. Com a skill `/brasa:subir-campanha`, o Claude envia as fotos do cliente, gera os criativos, monta o plano da campanha de Facebook e Instagram e, depois do "sim" do cliente, publica tudo pausado na Meta. Com `/brasa:analisar-anuncios`, lê o desempenho e propõe o que escalar, pausar ou trocar.

Instalar no Claude Code:

```
/plugin marketplace add matheusrfranca/brasa-plugin
/plugin install brasa@brasa
```

Depois de instalar, rode `/mcp`, escolha `brasa` e entre com a sua conta do Brasa. Instruções completas no README da raiz do repositório.
